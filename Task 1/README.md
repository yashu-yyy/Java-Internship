# Java Basics & OOP Fundamentals

This project demonstrates fundamental Java programming concepts including loops, conditions, arrays along with OOP features such as classes, objects, inheritance, polymorphism, and encapsulation.

Concepts:
- for,while loops
- if,else if,else conditions
- Arrays
- Classes & Objects
- Inheritance
- Polymorphism
- Encapsulation - Getters and setters

Programs:
- Conditions.java
- Loops.java
- ArraySum.java
- DerivedClass.java
- GetterSetter.java
